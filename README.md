The repo "blazor-gcp-cloud-run" contains .NET C# sources and my article PDF describing the creation, 
dockerization and deployment to Cloud Run of a C# .Net 8 Blazor Web App. The paper was published on CodeProject in August 2024. Unfortunately, the CP-forum is not active anymore, but the paper can still be found via Wayback Machine: https://web.archive.org/details/https://www.codeproject.com/Articles/5353867/Containerizing-a-NET-8-Blazor-application-and-depl
