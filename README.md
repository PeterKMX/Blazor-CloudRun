The repo "mypapers/blazor-gcp-cloud-run" contains .net C# sources and my paper describing the creation, 
dockerization and deployment (to Cloud Run) of a C# .Net 8 Blazor Web App. My aim has been to assess the 
procedures and steps in preparation for automated DevOps pipeline approach. 
The paper which I published in August 2024 can be accessed at CodeProject:
https://www.codeproject.com/Articles/5353867/Containerizing-a-NET-8-Blazor-application-and-depl
